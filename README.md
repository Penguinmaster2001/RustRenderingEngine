
# Wgpu renderer

This project is a simple rendering crate written in Rust. I intend to add interoperability with C# in the future.

I'm using the [wgpu](https://crates.io/crates/wgpu) crate for gpu stuff.

I'm loosely following [this](https://sotrh.github.io/learn-wgpu/) tutorial by [Ben Hansen and contributors](https://github.com/sotrh/learn-wgpu).
